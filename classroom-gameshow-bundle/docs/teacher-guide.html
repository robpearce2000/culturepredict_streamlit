Teacher guide · first edition

Two 3D revision games for the front of the classroom, inspired by classic TV quiz formats. They share one question bank and run from a single file, with no internet connection, logins or installs.

What's in Showtime

Over the Edge

Two players take turns to answer. A correct answer wins a counter: choose a lane from 1 to 4 and watch it bounce down the pegs onto the moving shelf. Every counter pushed over the front edge wins £100. In the final, the players team up to push the gold jackpot counter over the edge for £5,000.

Outpace

In the Deal Round each player picks a deal (a bigger prize gives the Hunter a shorter gap) and answers their way home before being caught. Then the pair face a 60-second Final Sprint: +1 for each right answer, −1 for each wrong one, against a target set by their pot.

  • One shared question bank. Pick a set once and both games use it. Add your own sets by pasting plain text.
  • Starter packs. 191 AQA-style questions for GCSE Combined Science (Biology, Chemistry and Physics packs plus an all-in-one mix), and a 61-question Homeostasis lesson set. These are written to match the AQA specification topics; they are not produced or endorsed by AQA.
  • Wrong-answer tracking. Every wrong answer is saved against the player's name in both games, so each player's weakest topics follow them from game to game.
  • A friendly host. Professor Pip presents Over the Edge and greets you on the menu. You can rename and restyle him.

Getting started

  1. Save classroom-gameshow-bundle.html somewhere on your computer, such as your Documents folder or a memory stick. Keep the same copy each lesson, because your question sets are saved for that browser.
  2. Double-click it. It opens in your web browser (Chrome, Edge, Firefox or Safari). No internet connection is needed.
  3. Put it on the board in full screen (press F11 on Windows, or Ctrl+Cmd+F on a Mac).
  4. On the menu, check the Questions in use line, then choose a game.
Tip: if a game feels slow on an older classroom PC, set Graphics to Low on the menu. It turns off shadows and glow effects without changing the game.

Setting up a game

Each game opens on a setup card. Type the two players' names (or team names), check the question set and press Start (or Enter).

  • Over the Edge also lets you choose the number of Round 1 questions per player (4, 6 or 8), the number of final questions (8, 12 or 16) and how hard the jackpot is to win.
  • Tick Pick more questions from topics each player got wrong before to steer questions towards each player's weak topics.
  • Use ◀ Menu (or Esc) in the top corner to go back to the menu at any time. You will be asked first if a game is in progress.

Running the games

Over the Edge

  1. Read the question aloud. Press Show answer if you want the class to see it.
  2. Mark it Correct or Wrong. If wrong, the other player can steal it.
  3. The winner picks a lane (1 to 4) with the buttons, the keys, or by tapping the machine.
  4. Watch for ★ wildcard counters: a bonus drop, £250, or a steal of up to £150.
  5. In the final, the pair work as a team. Each correct answer wins two counters.

Outpace

  1. Player 1 picks a deal: Cautious (300 points, Hunter 5 steps back), Standard (600, 3 back) or Bold (1,000, 1 back).
  2. Show the answer, then mark it. Right moves the player a step home; wrong moves the Hunter a step closer.
  3. Reach home to bank the deal. If caught, the player banks half.
  4. After both players, the Final Sprint starts: 60 seconds, taking turns. Each player can pass once.
  5. Reach the target to escape with the pot. If not, the Hunter catches the team.

Tips for running it with a class

  • Teams, not just two pupils. Split the room into two halves and type team names. Let each team confer for ten seconds, then take one answer from a nominated pupil.
  • Everyone answers. Ask the whole class to write each answer on mini whiteboards before you reveal it, so the game drives retrieval practice for everyone.
  • Use "Any two" answers generously. Many answers list several acceptable points. You are the judge, so accept good alternatives.
  • Short on time? In Over the Edge choose 4 Round 1 questions and 8 final questions: a game then takes about 15 minutes. Outpace usually takes 10 to 15 minutes.
  • Revisit weak topics. The results screen lists each player's missed questions and their weakest topics across all games. Use it to plan a starter for next lesson.

Adding your own questions

Open Question bank on the menu (or Manage the question bank on a setup card). Type a name for the set, paste your questions in this format, and press Save as new set:

Subject: Chemistry
Topic: Bonding
Q: What type of bonding is in sodium chloride?
A: Ionic
Q: Why can metals conduct electricity?
A: They have delocalised electrons that can move through the structure

Topic: Rates of reaction
Q: Give two ways to increase the rate of a reaction.
A: Any two: increase temperature, increase concentration, increase surface area, add a catalyst
  • The Subject and Topic lines apply to every question below them until the next one. Topics drive the weak-topic tracking, so keep topic names consistent between sets.
  • Every Q: line needs an A: line straight after it. Blank lines are ignored. Question sets from earlier versions of these games use the same format and paste straight in.
  • A new set becomes the set in use for both games straight away. Use the round buttons to switch sets.
  • Rename, Edit questions or Delete your own sets from the list. Deleting asks you to tap twice.
  • The built-in packs cannot be changed, but Copy to edit makes your own copy that you can trim or add to.

Moving to another computer: backups

Press Save backup file to download one file containing all your own sets and every player's wrong-answer history. On the other computer, open the bundle, choose Question bank → Load backup file and pick that file. Loading a backup only adds; it never deletes anything already there, and loading the same file twice adds nothing new.

Players' wrong answers

History is saved by player name, so use the same spelling each time (capital letters do not matter). The question bank lists every saved player; Clear removes one player's history. A player's history can also be cleared from the results screen.

Settings and accessibility

SettingWhat it does
SoundAll sounds are short effects made by the browser. There is no music.
Text sizeLarge makes every panel, question and button bigger for the back of the room.
Reduced motionStops camera sway, screen shake and the flash when the Hunter catches someone, and shows the host's words at once. It starts switched on if your computer asks for reduced motion.
GraphicsLow turns off shadows and glow and draws at standard resolution, for older PCs.

Colours meet the WCAG AA contrast guidelines. Nothing relies on colour alone: players are also marked ● and ■, wildcard counters carry a ★, the Hunter and the runner are labelled, and buttons show ✓ and ✗ as well as green and red.

Privacy and data protection

No data leaves the computer. Showtime makes no network connections at all: no analytics, no tracking, no accounts and no adverts. It even includes a browser security rule that blocks connections.

Question sets, player names, wrong-answer history, the host's look and your settings are saved only in the web browser on the computer you are using (in its local storage). They are not sent to us or anyone else.

For UK GDPR, this means the school stays in control: data stays on the school's device, you can delete a player's history at any time from the question bank, and a backup file is only created when you choose to save one. If you use pupils' names, treat backup files like any other file containing pupil data. You can also use first names, initials or team names instead.

Troubleshooting

ProblemWhat to try
The file opens as text, or in a preview paneDownload or copy it to your computer first, then double-click it. Previews in email, Teams or OneDrive cannot run it.
"3D graphics are switched off"Try another browser (Chrome, Edge, Firefox or Safari). If it still appears, ask IT to turn on hardware acceleration in the browser settings.
The game is jerky or slowSet Graphics to Low. Close other tabs and video calls.
No soundCheck Sound is on, the board's speakers are on, and the volume is up. Browsers only play sound after the first click or key press.
My question sets have goneSets are saved in one browser on one computer. Open the same file in the same browser you used before. Private or guest windows forget everything when closed, and some school setups clear browser data at log-off: keep a backup file and load it when needed.
"This browser is blocking storage" messageThe games still work, but nothing is kept after you close the page. Use a normal (not private) window, or keep a backup file.
"No Q: and A: pairs found"Check each question line starts with Q: and is followed by a line starting with A:.
Text is hard to read from the backTurn on Large text size and use full screen (F11).
I pressed a key and nothing happenedClick once on the game area first, so the browser knows the keys are for the game. Keys are ignored while you type in a box.
